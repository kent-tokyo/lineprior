# v0.11.0 benchmark snapshot

This is a reproducible local snapshot, not a release gate or a downstream-quality claim.

- Date: 2026-09-02 (Asia/Tokyo)
- Host: Apple arm64 (model string unavailable in the restricted shell)
- Toolchain: `rustc 1.97.0`, `cargo 1.97.0`
- Command: `cargo bench -p lineprior --bench scoring --locked -- --sample-size 10 --warm-up-time 0.1 --measurement-time 0.2 --noplot`

Criterion reported the following ranges:

| Benchmark | Time range |
|---|---:|
| `build_small_1000obs` | 150.51–153.52 µs |
| `build_medium_10000obs` | 1.3748–1.3948 ms |
| `build_large_50000obs` | 8.7034–15.836 ms |
| `build_from_reader_large_50000obs` | 33.055–35.206 ms |
| `trie_materialize_500_states_order4` | 803.93–820.21 µs |
| `flat_context_query_order4` | 326.82–388.96 ns |
| `trie_context_query_order4` | 146.77–151.86 ns |
| `macro_actions_5000obs_window2to4` | 6.0792–10.845 ms |

The trie query workload was faster than the flat backoff lookup in this synthetic case, while
materialization has an up-front cost. The macro-action result includes eager sorting/window
aggregation. These figures use only synthetic data and ten samples; outliers were reported by
Criterion. A downstream improvement claim still requires a declared real dataset, split,
baseline, abstention budget, and held-out result.
